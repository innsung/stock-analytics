# V3.2.1 Phase 5.85 Historical Chain Document Validation

Phase 5.85 downloads each unique child and candidate-primary OpenDART document for the 59 chains prepared in Phase 5.84. Cached documents are reused on repeat runs.

The audit requires the child and parent bodies to contain the expected corporate-action mechanic and requires role-specific amendment, attachment, or completion semantics. A semantic match confirms only that the documents belong to the same type of legal-event chain. It does not resolve either row or authorize a total-return adjustment until the primary mechanics are validated.
