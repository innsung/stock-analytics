# V3.2.1 Phase 5.95 — 아모레퍼시픽 계열사 구조개편 검증

Phase 5.93 직접 재파싱 대상으로 남은 아모레퍼시픽의 합병 및 주식교환 2건을 검증한다.

- 합병 결정의 지배 문서는 `20210621000143`이며, 에스트라 주주에게 자기주식을 대가로 교부한다. 합병신주는 없다.
- 주식교환 결정의 최종 정정 문서는 `20210623000067`이며, 코스비전 주주에게 자기주식 및 제한된 신주를 대가로 교부한다.
- 두 거래 모두 기존 아모레퍼시픽 주주의 주식 수를 일률적으로 변경하지 않는다.
- 거래일과 신주 상장일 주변 KRX 수정/비수정 종가에 조정 경계가 없어야만 `NOT_APPLICABLE` 근거를 생성한다.

이 단계는 완료보고서를 법적 메커니즘의 지배 문서로 사용하지 않고 최초/최종 결정 공시의 구조화 조건을 사용한다.
