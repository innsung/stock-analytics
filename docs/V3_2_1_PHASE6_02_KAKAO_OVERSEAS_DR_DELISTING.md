# V3.2.1 Phase 6.02 — Kakao overseas DR delisting

This phase consolidates Kakao's decision and completion disclosures for the 25 May 2023 delisting of its GDRs from the Singapore Exchange.

The two rows are promoted to `NOT_APPLICABLE` only when the official DART documents confirm the SGX GDR and effective date, the disclosure inventory contains one exact receipt per row, and domestic KRX adjusted-versus-raw prices show no adjustment breakpoint. The overseas venue event does not create an additional return event for holders of Kakao's domestically listed common shares.
