# V3.2.1 Phase 6.35 — Release Curation Manifest

This phase expands the repository-level hold into a file-level, SHA-256-addressed curation plan. Source, tests, documentation, operational scripts, safe configuration templates, and root metadata are proposed for inclusion. Runtime files are proposed for exclusion, while live configuration remains subject to manual review.

`PLAN_READY` does not authorize staging, deletion, commit, or tagging. The manifest is evidence for an explicit operator curation decision.
