# V3.2.1 Release

V3.2.1은 현재 지원되는 유일한 공개 버전입니다.

## 검증 상태

- 기업행위 원장 399건: VERIFIED 25, NOT_APPLICABLE 371, UNRESOLVED 3
- 처리 가능한 잔여 큐: 0건
- 비 PIT 배당 2건은 의도적으로 보류
- 복합 분할 1건은 외부 증거 부족으로 차단
- 품질, 무결성, 복원, 런타임 및 클린룸 배포 검증 통과

## 공개 인터페이스

현재 ML 진단 인터페이스는 `ml-diagnose-v321`입니다. 과거 진단 버전의 CLI와 전용 테스트는 제거되었습니다. V3.2.1 내부에서 재사용되는 특징 처리, 연구 경계 및 포트폴리오 계산은 `diagnostics_*_v321.py` 기반 모듈로 통합되었습니다.
